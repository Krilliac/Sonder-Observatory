# Protocol workspace

The existing [event schema](observatory-events.schema.json) and
[protocol notes](../docs/TELEMETRY_PROTOCOL.md) are the current design artifacts.
This scaffold does not revise or generate either one.

Protocol package ownership, compatibility/versioning policy, generated bindings,
and validators remain future work. Do not add a competing event envelope in the
viewer source tree. No network service is implemented here.
