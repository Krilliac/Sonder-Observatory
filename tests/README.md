# Tests

Vitest unit tests (`npm test`). They cover the envelope and discovery
validators and their drift against `protocol/` (`protocol-schema-drift`,
`protocol-discovery-drift`), fixture parsing and reproducibility, replay
ordering/dedupe/gaps and the cursor, metric derivation (including per-producer
request spans and cumulative drop accounting), the `.sobs` recording round
trip, live ingest (`ingest/live/`: the WebSocket/SSE/NDJSON client against
`scripts/fake-live-producer.mjs`, the multi-producer connection manager with a
fake fetch and WebSocket, the fake producer's role modes and auth), the desktop
bridge, diagnostics, topology, performance budgets and design-token
resolution.

Browser end-to-end tests live in `e2e/` (Playwright, `npm run test:e2e`).

## Live producer conformance

`tests/conformance/live-producer.test.ts` checks a running producer against
the live producer protocol v1 (docs/TELEMETRY_PROTOCOL.md). It is reported as
skipped unless `SONDER_CONFORMANCE_URLS` is set:

```bash
SONDER_CONFORMANCE_URLS=http://127.0.0.1:11437,http://127.0.0.1:11435 \
SONDER_CONFORMANCE_ORIGIN=http://127.0.0.1:4173 \
npx vitest run tests/conformance
```

`SONDER_CONFORMANCE_TOKEN` adds `Authorization: Bearer <token>` (never
printed). `tests/ingest/live/conformance.test.ts` proves the checks pass on
the fake producer and fail on broken producers.
